# 🧭 Dev Dashboard
**Dev Dashboard** is a React-based web application that lets developers build their own personal dashboard out of small widgets, like GitHub stats, news, weather, and crypto prices.
## ✨ Features
- 🧩 Add widgets for GitHub, Hacker News, weather, and crypto prices.
- ❌ Remove any widget you don't need.
- 🖱️ Drag and drop widgets to rearrange them.
- ↔️ Resize widgets to take more or less space.
- ⚙️ Change each widget's settings, like a username or a city.
- 💾 Your layout and settings are saved in the browser.
- 🌗 Switch between light and dark themes.
## 🛠️ Tech Stack
- React
- JavaScript
- CSS
- Vite
## 🚀 Getting Started
### Prerequisites
Install [Node.js](https://nodejs.org/) before running the project.
### Installation
1. Clone this repository:

   git clone https://github.com/kashyapsunaina/dev-dashboard.git

2. Navigate to the project folder:

   cd dev-dashboard

3. Install dependencies:

   npm install

4. Start the development server:

   npm run dev

5. Open the local URL displayed in your terminal.
## 📁 Project Overview
Each widget fetches its own data and shows its own loading and error messages. By default the widgets show sample data. Tick the **Live data** box to load real data from the GitHub API, Hacker News API, Open-Meteo, and CoinGecko.
## 🎯 Project Objective
This project demonstrates practical skills in React, reusable components, state management, working with APIs, localStorage, and CSS styling.
